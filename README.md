# Netflix EDA Project

Exploratory Data Analysis (EDA) of Netflix movies and TV shows using Python, Pandas, Matplotlib, and Seaborn.

---

##  Project Overview

This project analyzes the Netflix dataset to explore:
- Total number of movies and TV shows
- Release year trends
- Ratings distribution
- Most popular genres
- Data visualization using charts and graphs

The project also demonstrates data cleaning, grouping, filtering, and visualization techniques using Python libraries.

---

##  Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

---

##  Dataset

Dataset used:
- `netflix_titles.csv`

The dataset contains information about Netflix movies and TV shows including:
- Title
- Type
- Release Year
- Rating
- Genre
- Director
- Cast
- Country

---

## Features

 -Handle missing values using `fillna()`  
 -Analyze Movies vs TV Shows  
 -Search content by release year  
 -Find years with highest releases  
 -Analyze ratings distribution  
- Analyze top genres  
 -Visualize data using:
- Bar Charts
- Count Plots
- Pie Charts

---

##  Visualizations Included

- Top release years
- Movie vs TV Show count
- Rating distribution
- Genre analysis
- Pie chart for ratings
